# Task 3 – Data Cleaning

## Overview
This project was completed as part of my Data Analytics internship at Oasis Infobyte.

The objective was to clean and prepare a retail sales dataset for further analysis and business intelligence applications.

## Work Performed
- Inspected the dataset structure
- Identified missing values
- Checked data types
- Handled missing and inconsistent values
- Cleaned the dataset
- Validated the cleaned data
- Exported the cleaned dataset

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Files
- `OIBSIP_Task3_Data_Cleaning.ipynb` – Data cleaning notebook
- `retail_sales_dataset_cleaned.csv` – Cleaned dataset
