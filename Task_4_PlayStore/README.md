# Google Play Store App Analysis

## Internship
Oasis Infobyte – Data Analytics Internship

## Project Overview
This project analyzes Google Play Store applications to identify patterns in app categories, ratings, installs, pricing, app size, and user sentiment.

## Objectives

- Analyze the distribution of apps across categories
- Study app ratings by category
- Analyze the relationship between app size and installs
- Compare free and paid applications
- Analyze pricing patterns of paid apps
- Perform sentiment analysis on user reviews
- Generate business insights from the analysis

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis
5. Data Visualization
6. Sentiment Analysis
7. Business Insights
8. Recommendations

## Key Findings

- FAMILY has the highest number of applications.
- Average ratings are generally high across categories.
- App size does not show a clear strong relationship with installs.
- Most paid apps are concentrated in lower price ranges.
- Positive reviews dominate across most categories.

## Conclusion

The analysis provides insights into application popularity, user ratings, pricing patterns, app size, and customer sentiment. These insights can help developers understand market trends and identify opportunities to improve application performance and user experience.
