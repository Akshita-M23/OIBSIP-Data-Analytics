# Task 1 – Retail Sales Exploratory Data Analysis

## Overview
This project was completed as part of my Data Analytics internship at Oasis Infobyte.

The objective was to perform Exploratory Data Analysis (EDA) on retail sales data and identify meaningful sales trends and patterns.

## Work Performed
- Loaded and inspected the retail sales dataset
- Checked data types and missing values
- Performed descriptive statistical analysis
- Converted and analyzed date information
- Analyzed monthly sales trends
- Analyzed quarterly sales trends
- Created data visualizations
- Derived business insights from the sales data

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Files
- `Task_1_Retail_Sales_EDA.ipynb` – EDA notebook
- `retail_sales_dataset.csv` – Dataset used for analysis
